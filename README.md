# 🌐 Network Lab

Живі демо, скрипти й лабораторні до курсу з комп'ютерних мереж. Кожне заняття — окрема папка: інтерактивні HTML-сторінки, Python-скрипти по рівнях OSI, Docker-сценарії з втратами пакетів і повноцінна «міні-мережа» на Linux namespaces.

Ідея проста: **не розповідати про протоколи, а показувати їх наживо** — у терміналі, у Wireshark і в браузері.

## 2️⃣–3️⃣ Модель OSI та TCP/IP

Один маленький скрипт на кожну ідею, впорядковані знизу вгору по рівнях OSI: від NRZ/Manchester-кодування та Ethernet-кадру з CRC до TLS, SSH-рукостискання й WebSocket-чату.

```bash
cd "Заняття 2, 3. Модель OSI та TCP|IP"
uv sync                  # один раз: створює .venv (scapy)
uv run L3_traceroute.py
```

Скриптам, що потребують root (`L2_arp_scan.py`, `ALL_sniffer.py`), передавайте Python із venv напряму:

```bash
sudo .venv/bin/python ALL_sniffer.py
```

Також тут є **«Мережевий полігон»** і посібник до нього (HTML). Повна таблиця скриптів — у [README заняття](<Заняття 2, 3. Модель OSI та TCP|IP/README.md>).

## 4️⃣ TCP, UDP та порти

Кожне демо — окрема папка з `run_demo.sh`, очікуваним виводом (`expected_output.txt`) і поясненням (`explanation_uk.html`). Linux-інструменти (`tc netem`, `tcpdump`, `ss`, `iptables`) працюють у Docker, тож демо однаково запускаються на macOS і Linux без `sudo`.

| Демо | Що показує |
|---|---|
| `tcp-demo` | Рукостискання, сегменти з даними, закриття з'єднання |
| `01-zero-window` | Сервер не читає → вікно падає до 0 → `send()` клієнта зависає |
| `02-retransmissions` | Ретрансляції TCP при 5% втрат, із SACK і без |
| `03-slow-start` | Ріст `cwnd`: 10 → 20 → 40 → … за кожен RTT |
| `04-clock-tcp-vs-udp` | Годинник по TCP і UDP при 10% втрат: «застарілі дані гірші за втрачені» |
| `05-closed-vs-filtered` | Закритий порт (миттєвий RST) проти фаєрвола (тиша й тайм-аут) |
| `06-message-boundaries` | UDP зберігає межі повідомлень, TCP-потік — ні |
| `07-listen-backlog` | `listen(backlog)` без `accept()` — черга заповнюється |
| `08-browser-ports` | Порти вашого браузера просто зараз: TCP :443, QUIC, ефемерні порти |
| `09-reliable-udp` | Надійність поверх UDP: номери, ACK, повтори, ковзне вікно |

```bash
cd "Заняття 4: TCP, UDP та порти/03-slow-start"
./run_demo.sh
```

Параметри кожного демо описані в коментарі на початку його `run_demo.sh`.

## 5️⃣ DNS та DHCP

«Міні-інтернет у ноутбуці»: роутер, DHCP-сервер, DNS-сервери й клієнти на Linux network namespaces. Покроково: DHCP DORA, оренда й резервації, а потім DNS — від `dig` до рекурсивного резолвінгу.

```bash
cd "Заняття 5: DNS та DHCP/dns-dhcp-lab"
sudo bash lab-up.sh      # підняти лабораторію
sudo bash lab-down.sh    # прибрати
```

Потрібні Linux (або VM / контейнер з `--privileged`), root і пакети `iproute2 dnsmasq-base isc-dhcp-client bind9 unbound dnsutils tcpdump`. Команди до слайдів — у [`lab-steps.md`](<Заняття 5: DNS та DHCP/dns-dhcp-lab/lab-steps.md>), покроковий гайд зі скриншотами — у `dns-dhcp-lab-guide.html`.

## 🛠️ Що знадобиться

- **Python 3.11+** і [uv](https://docs.astral.sh/uv/) — для заняття 2–3
- **Docker** — для заняття 4

- Браузер — для HTML-демо та пояснень

## ⚠️ Важливо

- Сканування мережі (ARP-скан, сніфер) запускайте **лише в мережах, де маєте на це дозвіл**.
- Багатьом демо потрібен інтернет. Wi-Fi на заходах іноді блокує ICMP або порт 22 — тримайте під рукою точку доступу з телефона.
- Основна платформа для тестів — macOS; Docker-демо працюють і на Linux.
